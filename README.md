# Aug Video Animation 6 - Core Message

Live Demo: [https://rifaterdemsahin.github.io/aug-video-animation-6-core-message/](https://rifaterdemsahin.github.io/aug-video-animation-6-core-message/)

## Overview & Core Message
This project presents an interactive 12-scene video production script and animation prompt breakdown guiding the viewer toward Erdem's core message:
> **"As AI raises skill expectations, the solution isn’t less education—it’s continuously educating yourself to uplift your outer circle."**

---

## Stages of Video Production

### Stage 1: Core Message & Initial 12-Scene Script (Gemini Conversation)
* **Objective:** Define the core message and create a 15-second reel (~8-second voiceover) paired with visual animation prompts for Google Generative Video AI (Lumiere / Imagen Video style).
* **12-Scene Metaphor:** Each scene utilizes "Step 1 of 12" through "Step 12 of 12" as a visual anchor.

### Stage 2: Personal Story Mapping
* **Objective:** Integrate Erdem's personal story into the narrative:
  1. Economic depression in IT & needing new connections.
  2. Rapid increase of AI and skyrocketing skill expectations.
  3. Turning inward rather than blaming university education.
  4. Realizing growth is collective and building a shared knowledge hub.
  5. Scaling impact to empower the outer circle.

### Stage 3: Sanity Check & Script Feedback
* **Objective:** Refine script flow, review metaphors (e.g., replacing obscure terms like "positronic library" with "shared knowledge hub"), and structure high-impact script options (Option A: Direct & Concise vs Option B: Sci-Fi / Tech Variant).

### Stage 4: ElevenLabs Audio Production
* **Objective:** Format voiceover scripts with SSML tags (`<speak>`, `<prosody>`, `<break>`, `<emphasis>`) and precise voice settings (Stability: 0.40–0.50, Clarity: 0.75–0.85, Style Exaggeration: 0.15–0.25) for synthetic voice output.
